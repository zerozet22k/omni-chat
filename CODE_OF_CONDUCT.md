# Code of Conduct

## Our Standard

This repository should remain a respectful, professional, and useful place to collaborate.

Participants are expected to communicate constructively, focus criticism on ideas and code rather than people, respect different backgrounds and experience levels, and protect private or sensitive information.

Harassment, discrimination, threats, doxxing, sexual harassment, personal attacks, and deliberately disruptive behavior are not acceptable.

## Scope

This code applies to issues, pull requests, reviews, discussions, and other project spaces connected to this repository.

## Enforcement

The maintainer may edit or remove inappropriate content and may restrict participation when necessary to protect the project and its contributors.

Serious concerns can be reported privately to the repository owner through the contact information on their GitHub profile.
